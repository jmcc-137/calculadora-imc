# Calculadora de IMC (Índice de Masa Corporal)

Esta es una aplicación web simple que permite calcular el **Índice de Masa Corporal (IMC)** ingresando el peso y la altura del usuario. Está desarrollada con **HTML**, **CSS** y **JavaScript** puro, sin frameworks ni librerías externas.

## 💡 Funcionalidades

- Ingreso de peso y altura a través de un formulario.
- Cálculo automático del IMC al enviar el formulario.
- Muestra un mensaje y una imagen según el resultado:
  - Bajo peso
  - Peso normal
  - Sobrepeso
  - Obesidad
- Desactiva los inputs tras el envío para evitar nuevos datos hasta hacer "Reset".
- Botón de **Reset** para limpiar el formulario y volver a calcular.

## 🧩 Tecnologías utilizadas

- **HTML5**: estructura básica del formulario y la interfaz.
- **CSS3**: estilos para mejorar la apariencia visual.
- **JavaScript**: lógica para el cálculo y control de eventos.

## 🚀 Cómo usarlo

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Ingresa tu peso (en kilogramos) y altura (en metros).
4. Presiona el botón de enviar.
5. Observa tu resultado y presiona "Reset" si deseas intentarlo de nuevo.
